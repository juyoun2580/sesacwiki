1. Git이란

Git은 파일 변경 이력을 추적하는 분산 버전 관리 시스템입니다. 여러 명이 동시에 작업해도 변경 내용을 안전하게 합칠 수 있습니다.

2. 기본 명령어

가장 자주 쓰는 명령어는 변경사항을 기록에 올리는 add/commit, 원격 저장소와 주고받는 push/pull입니다.

복사 
git add .
git commit -m "작업 내용"
git push origin main
